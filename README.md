# AppDev 387 - Professional Web & App Development

This is the official repository for **AppDev 387**, a premium tech agency based in Zenica, BA.

## Features
- **Modern Dark Theme**: High-tech aesthetic with cyber-cyan and electric-purple highlights.
- **Glassmorphism UI**: Beautifully crafted components with frosted glass effects and subtle borders.
- **Animations**: Entrance animations using Intersection Observer and a dynamic "Circuit Orb" hero element.
- **Privacy-First Focus**: Special section dedicated to the **Custom Cryptic Chat** product.

## Tech Stack
- HTML5 (Semantic & SEO Friendly)
- CSS3 (Custom Design System, Flexbox, Grid, Animations)
- JavaScript (Intersection Observer, DOM Interaction)
